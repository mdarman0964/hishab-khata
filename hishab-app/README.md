# আমার খাতা — Android অ্যাপ

হাজিরা খাতা, ক্যাশবুক ও মিলের হিসাব — তিনটাই এক অ্যাপে। হিসাব ফোনেই সেভ থাকে, ইন্টারনেট লাগে না।

## অটোমেটিক APK বানানোর নিয়ম
1. GitHub-এ নতুন repository খুলুন (যেমন `hishab-khata`)।
2. এই ফোল্ডারের **সব ফাইল** (লুকানো `.github` ফোল্ডারসহ) repository-তে আপলোড করুন, ব্রাঞ্চ `main`।
   - কম্পিউটার থেকে `git push` করাই সবচেয়ে নিরাপদ।
   - ওয়েবসাইটে আপলোডে `.github` বাদ পড়লে: Add file → Create new file → নাম দিন `.github/workflows/android.yml` → ফাইলের লেখা পেস্ট করুন।
3. আপলোড হলেই **Actions** ট্যাবে বিল্ড শুরু হয় (৫–১০ মিনিট)।
4. শেষ হলে repository-র **Releases → "সর্বশেষ APK"** থেকে `hishab-khata.apk` ডাউনলোড করে ফোনে ইনস্টল করুন
   (ফোন জানতে চাইলে "এই উৎস থেকে ইনস্টলের অনুমতি" দিন)।
5. এরপর কোড বদলে আপলোড করলেই নতুন APK নিজে তৈরি হবে।

## ক্লাউড ব্যাকআপ (ইমেইল-পাসওয়ার্ড লগইন, Firebase)
একবার সেটআপ করলে লগইন করা সব ফোনে হিসাব নিজে নিজে জমা ও মেলানো হবে।
1. [Firebase Console](https://console.firebase.google.com)-এ প্রজেক্ট খুলুন (বা আগেরটা নিন)।
2. **Build → Authentication → Get started → Sign-in method → Email/Password** চালু করুন।
3. **Build → Firestore Database → Create database** (প্রোডাকশন মোড; লোকেশন কাছের একটা, যেমন `asia-south1`)।
4. Firestore-এর **Rules** ট্যাবে `firebase/firestore.rules` ফাইলের লেখা পেস্ট করে **Publish** করুন। (এটাই নিশ্চিত করে কেউ অন্যের হিসাব দেখতে পারবে না।)
5. **⚙ Project settings → General** থেকে **Project ID** আর **Web API Key** কপি করে `www/firebase-config.js`-এ বসান, তারপর GitHub-এ আপলোড করুন।
6. নতুন APK ইনস্টল করে হোম পেজে ইমেইল-পাসওয়ার্ড দিয়ে "নতুন অ্যাকাউন্ট" চাপুন। অন্য ফোনে "লগইন" করলেই হিসাব চলে আসবে।

নিয়ম: ফোনের ডাটাই আসল, ইন্টারনেট না থাকলেও কাজ চলে, নেট এলে নিজে সিঙ্ক হয়। দুই ফোনে আলাদা বদল হলে প্রতিটা খাতার (হাজিরা/ক্যাশবুক/মিল) নতুন বদলটাই থাকে — তাই একসাথে দুই ফোনে লিখবেন না। একটা খাতার ডাটা ১ MB-এর বেশি হলে ক্লাউডে যাবে না (সাধারণ ব্যবহারে অনেক বছর লাগবে)। Google দিয়ে সাইন-ইন এখনো নেই।

## পুরনো হিসাব (কম্পিউটারের JSON) অ্যাপে আনা
1. `python tools/make_backup.py <যে ফোল্ডারে data.json, cashbook.json, meal.json আছে>`
2. যে লেখাটা ছাপা হবে সেটা কপি করুন → ফোনে অ্যাপের হোম পেজ → **ব্যাকআপ ও ফিরিয়ে আনা** → পেস্ট করে **ফিরিয়ে আনুন**।

## ফোল্ডার
- `www/` — অ্যাপের পেজ (এগুলোই APK-তে যায়)
- `desktop/` — আগের পাইথন সংস্করণ (কম্পিউটারে `python run.py`)
- `tools/build_www.py` — `desktop/` বদলালে `www/` আবার বানায়
- `.github/workflows/android.yml` — অটো-বিল্ডের নির্দেশ

## জেনে রাখুন
- এটা ডিবাগ APK: সরাসরি ইনস্টল হয়, কিন্তু Play Store-এর জন্য নয়।
- অ্যাপ মুছলে বা ডাটা ক্লিয়ার করলে হিসাব যায় — মাঝে মাঝে ব্যাকআপ শেয়ার করে রাখুন।
- মিলের রিপোর্ট: লেখা আকারে শেয়ার (হোয়াটসঅ্যাপ) ও Excel ফাইল। PDF এই সংস্করণে নেই।
